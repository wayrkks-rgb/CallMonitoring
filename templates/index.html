서버 추가

SSH 키 자동 등록
패스워드는 최초 1회 키 등록에만 사용되며 저장되지 않습니다.
등록 후에는 키 파일로 자동 접속됩니다.
ARS 서버 접근
ARS는 네트워크 드라이브(UNC)로 접근하며 SSH를 쓰지 않습니다. 접근 계정은 서버별로 입력하지 않고 공용 계정 1개를 아래에서 등록합니다.
로그 경로는 UNC 형식으로 등록하세요. 예: \\10.19.20.11\share\IS-IVR-{YYYY}-{MMDD}-{HH}.log
ARS 공용 계정 등록 확인 중...
비밀번호는 DPAPI로 암호화되어 저장됩니다(응답으로 노출 안 됨). 서비스 구동 계정과 동일한 계정으로 앱이 실행 중일 때 저장하세요 (그 계정에서만 복호됩니다).
* SSH 키 등록 후 서버 추가를 눌러주세요
